Privacy policy

Last updated: October 23, 2026

This OAuth client is used only by its owner, with rclone, to access the owner's own Google Drive.

  • What is accessed: files in the owner's Google Drive, read and written by rclone on the owner's own computer.
  • Where data goes: only between the owner's Google Drive and the owner's own computer. No data is sent to any other server, person or company.
  • Storage: the sign-in token is stored only in rclone's configuration file on the owner's computer.
  • Sharing: no data is shared, sold or used for advertising.
  • Other users: none. The app is not offered to anyone else.

Google API use complies with the Google API Services User Data Policy, including its Limited Use requirements.
